プルーフ・オブ・コンセプトのキャリアブランドのための34.7秒のスペックCMが、構想され、構築され、声が付けられ、スコアが付けられ、仕上げられるまでを、AIを用いて最初から最後まで解説します。

制作ステップ

パイプライン、順番に

  1. まずリファレンス。7つのマスターリファレンス（R1 から R7）を、ショットが存在する前に生成し、承認します。Frankie の全身、Frankie の顔、正確なスケールでの Frankie、Marcus のポートレート、Marcus の全身、キッチン、スタジオとスマートフォンのプレートです。
  2. 開始フレーム。すべてのショットは、Google Flow で Nano Banana Pro を使って作った静止画から始まります。添付するリファレンスは最大3つです。プロンプトはリファレンスを名指しし、ショットだけを記述します。キャラクターを言葉で再記述することは決してしません。
  3. モーション。承認済みの静止画はそれぞれ Omni Flash 1.1 でアニメーション化します。フレームから動画へ、1本の連続ショットでカットは入れません。モデルが対話を演じるため、くちばしと口が正しい音節で動きます。
  4. ボイス。生成した演技をセリフごとに抽出し、Speechify Studio Voice Changer でキャストの声に変換し、正確に元のタイムスタンプに戻します。そのためリップシンクは決して動きません。
  5. グラフィック。キャプション、価格バッジ、隅のバグ、スマートフォン画面のロゴ、エンドカードをブランドシートに合わせて作り、映像の上に合成します。
  6. 音楽とサウンド。Suno のトロピカルポップのベッドを小節のラインでカットし、対話の下でダッキングします。Suno の歌入りジングルがスポットを締め、小さな合成エフェクトがジョークを際立たせます。
  7. 編集。ショットを放送のタイミングで組み立て、-16 LUFS にミックスし、1080p マスターと faststart の Web エンコードとして仕上げます。
  8. チェック。生成前にすべてのプロンプトに自動チェックを実行します（この制作では238件）。完成した映像は台本に対してフレームごとにチェックします。

物語

1枚の長い請求書、1羽の小さなフラミンゴ

Marcus は、床にこぼれるほど長い電話の請求書を見て顔をしかめます。「うわ。これは大手キャリアの請求書だ。」スマートフォンほどの大きさのフラミンゴである Frankie は、コーヒーマグの横で片脚で立っています。「こんにちは。Frankie。Flamingo から来ました。」Marcus：「君は…フラミンゴだね。」

Frankie は請求書の上でバランスを取り、スマートフォンの横に立ち、マグの縁の上に立ちながらキャリアを売り込みます。全国カバレッジ、通話、テキスト、データ無制限、契約なし、隠れた手数料なし、月額 $25 からのプラン、番号とスマートフォンはそのまま使えます。乗り換えのセリフでは Marcus の肩に乗ります。

ボタンが冒頭の前提を回収します。Frankie は古い請求書を巣に変え、その中に落ち着いています。Marcus：「それは…僕の古い請求書？」Frankie：「やっと役に立ったね。」アナウンサー："Flamingo Mobile."パックショット、次に Frankie：「ピンクに乗り換えよう。」エンドカード、歌入りジングルとともに："Let's go, flaminGO!"

構成は古典的なマスコットスポットです。1つのゲーム（家具の上に立つ非常に小さなセールスマン）、高まり（売り込みのポイントごとに足場が悪くなります）、次に最初のショットに結びつくボタン、最後に行動喚起です。

ルック

フォトリアルな世界にいる CG マスコット

フォーマットは、保険やキャリアのマスコットがテレビで使うものです。Pixar 品質の 3D キャラクター、高さ約15 cm。本物のキッチンに本当に立っているかのように撮影します。Frankie の羽は温かいコーラル色で、本物のフラミンゴの色です。マゼンタからは意図的に離しています。マゼンタは本物のキャリアの保護されたトレードカラーだからです。本物のキャリア名は決して出しません。比較は「大手」のままにし、すべての主張はスペック広告の細則でカバーします。

スケールが幻想のすべてです。そのためリファレンス R3 でロックします。コーヒーマグとスマートフォンの間で、正確な大きさの Frankie です。R3 は Frankie が登場するすべてのショットに添付します。

Pixar スタイルの 3D フラミンゴ。コーヒーマグほどの高さで、温かいコーラル色の羽、暗い先端を持つ長く曲がったくちばし。明るく、機敏で、親切です。素晴らしいヒントを持つ親しみやすい隣人で、決して大声のセールスマンではありません。登場するたびにリファレンス R1、R2、R3 で演じます。

ボイスプラン

演技は残し、声だけを変える

Flow が生成した対話は、くちばしと口の動きすべてとすでにシンクしています。そのためタイミングは触れないものとして扱います。各キャラクターのセリフを、タイミングマップとともに1つのファイルに抽出します。そのファイルを選んだ1つの声で Speechify Studio Voice Changer に通します。次にすべてのセリフを元のタイムスタンプに戻します。この制作で測定したところ、変換したセリフはオリジナルに対して 0 ms のオフセットで着地し、エンベロープ相関は 0.87 から 0.96 でした。

  • Frankie：Speechify Voice Changer、声は Lindsey (F)、アクセントオン。ブリーフ：30代の明るく機知に富んだ声、温かく少しハスキー、中立的な北米の発音、明るいコメディのタイミング、前向きですが決して大声ではなく、アナウンサー読みではありません。
  • Marcus：生成したセリフに Speechify Voice Changer。ブリーフ：リラックスして温かく、中低音、自然で会話的、少し戸惑い、ユーモアがあり、演者ではありません。v5 では、David 自身が Speechify で冒頭のセリフを収録し、Frankie にレベルを合わせ、S01 を少し長くして「こんにちは。」にまだ間があるようにしました。
  • アナウンサー：Speechify のテキスト読み上げ、Julien (M)、速度とピッチはゼロ。ブリーフ：40代前半の温かく、明瞭で、自信のある中音域のカナダ人の読み。信頼できる地元サービスのための、洗練されたテレビCMのデリバリー。親しみやすく安心感があり、決して売り込み口調ではありません。
  • 合わせたセリフ：Frankie の2つのセリフをテキスト読み上げで録り直し、ピッチを保ったタイムストレッチで既存のくちばしの動きに一語ずつ合わせ、元の開始から 40 ms 以内に着地させました。

スコアとサウンド

Suno のベッド、Suno のジングル、小さな音

ベッド。Suno のトロピカルポップ、ハ長調、104 BPM。ウクレレのストラム、マリンバ、軽いスティールドラムのアクセント、フィンガースナップとハンドクラップ、温かく丸いベース、いたずらっぽい口笛のフック。ばかばかしいのではなく、晴れやかで自信があります。インストゥルメンタルです。ベッドは小節のラインでカットし、最後の3分の1の下で独自のブレイクダウンにつなぎ、最後のヒットがエンドカードに正確に重なるようにし、対話のすべてのセリフの下で約 9 dB ダッキングします。

ジングル。短い Suno の歌入りジングル、"Let's go, flaminGO!"。2番目の歌唱フレーズを、そのピックアップビートから使い、エンドカードが組み上がるにつれて "Let's go" と "flaminGO!" が画面の文字と重なるように配置します。

エフェクト。小さくドライで、ほとんどが合成です。請求書の下の紙のざわめきと滑り、Frankie の登場での柔らかいポップ、手を振るときの小さな羽ばたき、紙の上の足のタップ、信号バーが現れるときの3つの柔らかいポップ、Frankie がマグの縁に落ち着くときの陶器のチーンという音、パックショットでのきらめき、クローザーでの瞬き。Marcus の笑いと巣のショットの中の紙の音は、生成したクリップ自身の音声で、残しました。

編集

5カット、v1 から v5

  • v1（30.0秒）。最初の完全な組み立てです。10ショットすべて、オーバーレイ、音楽のつなぎ、-16 LUFS のミックス。仕組みは働きました。ブランドはその日のうちに差し替えました。
  • v2（33.6秒）。flaminGO へのリブランドです。オーバーレイをピンクとプラムに再着色し、ネームタグを書き直し、パックショットのスマートフォンに積み重ねたロゴを置き、隅のバグを追加し、エンドカードをブラッシュの上に歌入りジングルで作り直しました。S08 の立ち上がりは、より速い区間が不自然に読めたため、標準の 1.115倍速に均しました。上映時間は、ジョークを圧縮するよりも30秒を超えることを許しました。
  • v3（32.4秒）。ネームタグを右に移動し、Frankie の顔を決して覆わないようにしました。S08 の立ち上がりのタイミングを直し、Marcus のセリフを Frankie のレベルまで上げ、エンドカードの構築を歌の言葉に合わせて締めました。
  • v4（34.1秒）。S08 を S08b、巣に完全に差し替え、標準ルートで新しい声を付けました。隅のバッジをワードマークだけに簡素化し、大きくしました。
  • v5（34.7秒）、最終版。冒頭のセリフを David が Marcus の声で録り直し、先頭に配置しました。S01 を0.5秒長くし、それ以降のすべてを13フレーム後に移動しました。パックショットの価格バッジは早く出るため、カットをまたいで Frankie と重なることは決してありません。

プロンプトの整合性

生成前にチェックしました

プロンプトセットで238件の自動チェックに合格しました。内容は次の通りです。すべての画像プロンプトが完全なスタイルサフィックスで終わり、それを正確に1つだけ持ちます。すべてのショットプロンプトが、添付したリファレンスを名指しすることから始まり、材料は最大3つで、Frankie、Marcus、キッチンについての競合する言葉による記述を含みません。Frankie のすべてのショットにサイズアンカーがあります。Marcus のすべてのショットに R4 を添付します。すべてのモーションプロンプトがロック、Audio ライン、カットなしのラインで終わります。モーションプロンプトのカメラ前のセリフは台本と一言一句一致します。本物のキャリア名なし、マゼンタなし、借りたマスコットの特徴なしです。
