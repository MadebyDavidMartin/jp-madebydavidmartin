Director’s ChairAI活用講座
手法

The Director’s Chair.

この椅子はアナロジーです。映画だけの話ではなく、映像だけの話でもありません。

仕事が何であれ、映画、コードベース、文書、キャンペーン、ワークフローであれ、AIは今や制作の大きな部分を担います。それでも誰かが監督しなければなりません。意図を設定し、ツールを選び、仕事をブリーフし、指示を与え、テイクを判断し、何を公開するかを決めることです。それがディレクターの仕事であり、クルーがモデルで構成されても消えません。AIはクルーです。ディレクターは今もディレクターです。

概要
あらゆる仕事でAIを監督するためのアナロジー
基盤
カタログ規模で映画と映像を監督した経験と、テクノロジー企業の中でAIシステムを構築した経験から生まれました
問い
クルーにマシンを含むとき、どうすればディレクターであり続けられるか
着想

なぜディレクションが重要なのか。

AIは制作の経済性を変えました。制作が安くなっても、良い作品が生まれるわけではありません。

かつてチームが必要だったことが、今ではモデル、ツール、ワークフローの集合体と働く一人で制作できます。これは映画の現場だけの話ではありません。成果物がコード、文書、分析、ワークフローでも同じです。成果物は変わります。ディレクションは変わりません。生成が容易になると、ディレクションはより重要になります。ディレクションがなければ、AIはあらゆるものを増やします。バージョン、コンテンツ、アイデア、ノイズ、不整合を増やします。ボトルネックは、物を作ることから、何を作る価値があるかを決めることへ移ります。

ディレクターとは、すべてを自分でこなす人ではありません。ディレクターとは、すべてが正しい結果に向かっていることに責任を持つ人です。

つまり、知っていることです。私たちは何を達成しようとしているのか。これは誰のためか。良いとはどういう姿か。システムにはどんな情報が必要か。何が自動で起きるべきか。何に人間の判断が必要か。承認なしに公開してはいけないものは何か。AIは、誰が仕事をするかを変えます。結果への責任をなくすことはありません。

モデル

ツール利用者から、ディレクターへ。

従来のモデル

人間 → ツール → アウトプット

あなたが尋ね、モデルが応答し、あなたが採用、却下、再試行します。人間は本質的に、非常に高度なインターフェースを操作しているにすぎません。

ディレクターモデル

目的 → コンテクスト → クルー → ワークフロー → レビュー → 承認

人間がシステムを構築します。AIはクルーの一員になります。変化は、プロンプトからディレクションへの転換です。

何を作ろうとしているのか。プロンプトの前に、役割があります。

AIを監督するなら、映画であれ他の何であれ、意図に責任を持つのはあなたです。AIは仕事に貢献できます。目的を所有することはできません。最初のプロンプトは制作の始まりではありません。ディレクションするという決断こそが始まりです。

原則

8つのクリエイティブ原則。

私のクリエイティブ哲学です。テクノロジーはこれらに仕え、これらに取って代わることは決してありません。

01アイデアから始める

テクノロジーはアイデアではありません。モデルはアイデアではありません。ビジュアルスタイルはアイデアではありません。誰かに何を考え、感じ、行動してほしいかから始めてください。その下流のすべて、ツール、スタイル、制作計画は、その決定に仕えます。アイデアが弱ければ、どれだけ実行しても救えません。アイデアが強ければ、実行には仕えるべきものがあります。だからこそ、私が監督するすべての制作は、1つのビジュアルを作る前に、書かれたコンセプトから始まります。アイデアは、制作の資格を得る前に、紙の上で成り立たなければなりません。

02飾るのではなく、監督する

すべての視覚的決定はアイデアに仕えるべきです。優れたクリエイティブディレクションとは、付け加えることではありません。何が属し、何が属さないかを知ることです。抑制はクリエイティブな決定です。実践では、物語を進めない美しいショットを切り、自身に注意を引く巧妙なトランジションを取り除き、アイデアではないすべてのものから観客を守ることです。AIは、付け加えることを危険なほど容易にします。ディレクターの仕事は、アイデアだけが残るまで取り除き続けることです。

03作品に世界を与える

強いクリエイティブ作品には内部の論理があります。色、タイポグラフィ、構図、動き、音、キャラクター、環境、言語は、同じ世界に属しているように感じられるべきです。世界が一貫すると、観客は技巧に気づくことをやめ、アイデアを感じ始めます。その世界を構築するのは意図的な仕事です。リファレンスを集め、ルールを定め、新しい要素はすべて、入れる前に世界と照合します。これが、6部構成の映像シリーズを1つのシリーズらしく保ち、子ども向けチャンネルを大きなカタログと複数の制作時代にわたって一貫させたものです。

04すべてをリファレンスにする

AIはリファレンスを弱めるのではなく、強力にします。適切なリファレンスは、言葉では伝えられないことを伝えます。リファレンスは、決定を目に見える形にしたものです。何かを生成する前に、私はビジュアル世界を集めます。映画のフレーム、写真、イラストレーション、既存のブランド作品、そして私自身の過去の制作です。リファレンスは2つの仕事を同時にします。人間であれ機械であれ、すべての人を、「良い」とはどういう姿かで一致させます。そして生成ツールに、目指すべき具体的なものを与えます。それが、もっともらしい成果物と、監督された成果物の違いです。

05探索と実行を分ける

最初の仕事は、何が可能かもしれないかを発見することです。2つ目は、最も強い可能性を現実にすることです。AIは探索を安くし、ディレクションは実行を決断的にします。私はこれらの段階を厳密に分けます。探索の間は、すべてが許されます。大胆なバリエーション、間違った方向、幸運な偶然です。実行の間は、探索が終わり、決定が始まります。2つを混ぜることが、制作が漂流する原因です。生成を延々と続け、何も完成しません。ディレクターは、探索が止まり、制作が始まる時を決めます。

06不可能なことをテスト可能にする

クリエイティブテクノロジーが最も面白いのは、費用がかかりすぎる、遅すぎる、あるいは単に不可能だったアイデアを、実際に試作できるものに変えるときです。まず試作し、次に決めることです。フル撮影が必要だったコンセプトも、今では午後のうちに生成されたアニマティックでテストできます。試作は最終品質である必要はありません。このアイデアは機能するか、という問いに答える必要があります。これにより、野心的なアイデアをテストするコストが崩壊したため、クリエイティブディレクターが提案できるものが変わります。

07人間の視点を守る

AIは無限の可能性を生成できます。無限の可能性はクリエイティブ戦略ではありません。誰かが選ばなければなりません。テイストこそが戦略です。これは他の原則が仕える原則です。すべての段階で、視点を持つ人間が、何が残るかを決めます。観客は、生成された何千もの選択肢を体験することは決してありません。選ばれた1つを体験します。そして選ぶことこそが創造行為です。どれほど自動化されたワークフローでも、その選択をすることはできません。

08作品を公開する

クリエイティブディレクションは最終的に決定に終わります。別のプロンプトではありません。別のバリエーションではありません。作品は完成します。完了もクリエイティブな決定です。すべての制作には、誰かが「これは本当に十分に良いか」と問う時点が必要です。その問いは、生成が安くなるにつれて、より重要になります。ディレクターは決定に責任を持ちます。モデルが完成したと言ったからといって、何かが公開されることはありません。

テイスト

最も希少なスキル。

AIは1万の選択肢を生成できます。テイストとは、どれを追求する価値があるかを知ることです。

クリエイティブディレクションの一部は、強いアイデアが完全に形になる前にそれを見抜く能力です。何かが明らかすぎる、磨かれすぎている、安全すぎる、見慣れすぎている、多すぎる、足りない、あるいはちょうど良いと感じる時を知ることです。AIは可能性の生成を助けられます。その中から選ぶ責任を外部化することはできません。

創造が豊かになるほど、テイストはより価値あるものになります。

判断

実践におけるクリエイティブな判断。

判断は神秘的なものではありません。制作のすべての段階で問う、質問の集合です。

  1. Q1これはアイデアに仕えているか。

    そうでなければ、どれほど美しくても外します。

  2. Q2これは世界に属しているか。

    一貫性は目新しさに勝ります。

  3. Q3観客はこれを感じるか。

    観客が気づく技巧は、失敗した技巧です。

  4. Q4これは最も強いバージョンか。

    探索が報われるのは、最良の選択肢が勝つ場合だけです。

  5. Q5これは完成しているか。

    十分に良いとは、偶然ではなく決定です。

プロセス

アイデアから実行へ。

クリエイティブなアイデアは始まりにすぎません。目的はテクノロジーを目立たせることではありません。目的はアイデアを目立たせることです。

  1. ステージ 01コンセプト。

    アイデアは何か。観客は何を感じ、理解し、覚えるべきか。

  2. ステージ 02トリートメント。

    アイデアはどう見えるか。ビジュアル言語、トーン、リファレンス、世界とは何か。

  3. ステージ 03制作。

    実際にどう作るか。新興テクノロジーはどこで可能性を広げられるか。人間の技巧が最も重要なのはどこか。

クラフト

ビジュアル言語。

すべてのプロジェクトには独自のビジュアル文法が必要です。これらの決定は、スタイルより重要なものを生みます。アイデンティティを生むのです。

  1. 01構図。

    視聴者は最初に何を見るか。

  2. 02色。

    パレットはどんな感情の世界を作るか。

  3. 03タイポグラフィ。

    書体はどんな個性を持つか。

  4. 04モーション。

    作品はどう動くか。

  5. 05イメージ。

    ビジュアル世界を具体的に感じさせるものは何か。

  6. 06サウンド。

    観客が意識的に気づく前に聞くものは何か。

  7. 07ペーシング。

    作品はいつ呼吸するか。

  8. 08コントラスト。

    ある瞬間を別の瞬間より重要にするものは何か。

ワークフロー

AIアシストのクリエイティブワークフロー。

私はAIを、完成したクリエイティブを作るボタンとして使いません。クリエイティブプロセス全体を通して使い、すべてのゲートで人間の判断を置きます。

  1. 01探索。

    可能性を素早く生成します。

  2. 02リサーチ。

    コンテクストを構築し、課題を理解します。

  3. 03開発。

    ビジュアルの方向性、トリートメント、脚本、コンセプトを探ります。

  4. 04試作。

    本格制作に取りかかる前に、アイデアを具体化します。

  5. 05制作。

    画像、映像、音、モーション、コンテンツのためのAIアシストワークフローです。

  6. 06反復。

    バリエーションを生成し、方向性を素早くテストします。

  7. 07磨き上げ。

    最も強い素材を、人間の編集と判断でまとめます。

  8. 08完成。

    最終的なクリエイティブ判断を行います。

AIは、私が開けるドアの数を増やします。クリエイティブディレクションは、どのドアを通るかを決めます。

システム

クリエイティブ制作のための制作システム。

優れたクリエイティブは、個人の才能だけではありません。良い仕事が繰り返し生まれるシステムを作ることです。ブリーフ、リファレンス、ムードボード、クリエイティブ基準、テンプレート、制作ワークフロー、承認プロセス、アセットライブラリです。これらはクリエイティブと別物ではありません。クリエイティブを規模化できるようにする基盤です。

スタック

ディレクション＋コンテクスト＋ワークフロー＋ツール＋評価＋判断。

  1. 01ディレクション。

    目的、観客、制約、成功の定義です。

  2. 02コンテクスト。

    リファレンス、素材、ブランド基準、事例を、制作基盤として設計したものです。

  3. 03クルー。

    人、モデル、エージェント、ソフトウェアです。責任を分け、1つの成果に向かいます。

  4. 04ワークフロー。

    リサーチ → 下書き → 生成 → 評価 → 修正 → 承認。

  5. 05メモリー。

    キャラクター。ブランド。事実。音声。決定。リファレンス。制作に組み込まれた一貫性です。

  6. 06品質管理。

    基準、チェックリスト、評価基準、人間によるレビューです。

  7. 07承認。

    何を公開するかを誰が決めるのか。最終ゲートは人間のままです。

ループ

すべての制作が次を改善する。

定義 → 文脈化 → ディレクション → 制作 → 評価 → 改善 → 承認 → 学習

最後のステップが重要です。優れた制作は、単に成果物を生むだけではありません。次の成果物を生むシステムを改善します。

規範

Director’s Code。

AIはディレクターではありません。AIはクルーです。

ディレクターは目的地を定めます。クルーは道を作るのを助けます。
ディレクターは何が重要かを決めます。クルーは可能性を探ります。
ディレクターは基準を定めます。クルーはそれに向けて制作します。
ディレクターは物語を守ります。クルーはテイクを作ります。
ディレクターは作品をレビューします。クルーは決定から学びます。

そして作品の準備が整ったとき：ディレクターが何を公開するかを決めます。

それがこの椅子の要点です。コントロール自体のためではありません。結果への責任です。

ラボ

制作の道具箱が変わると何が起きるか。

私が新興テクノロジーに興味を持つ理由は1つです。以前は不可能だった何を可能にするかです。集めるためのツールではありません。探るためのクリエイティブ素材です。

焦点

生成映像、AIアニメーション、合成制作

アプローチ

デモではなく実験

クリエイティブテクノロジー

問いはどのツールかではありません。何が可能になるかです。

生成映像。AI画像システム。合成キャラクター。ノードベースのワークフロー。AIアシスト編集。プロシージャルアニメーション。生成サウンド。インタラクティブ体験。AIエージェント。新しい制作パイプライン。

問いは「どのAIツールを使うべきか」ではありません。問いは、「古い制作モデルの制約が消えたら、私たちは何を作れるか」です。

そこがクリエイティブテクノロジーの面白いところです。以下の各実験は、クリエイティブ制作がどこへ向かっているかについて、1つの問いを投げます。

実験

進行中の探求。

AIシネマトグラフィ

生成映像の中でカメラ言語を探ります。従来のシネマトグラフィの概念、レンズの選択、カメラの動き、ブロッキングは、生成ワークフローに翻訳できるか。

キャラクターの一貫性

複数のショットにわたって認識できるキャラクターを保つワークフローを構築します。固定リファレンス、複数パスの生成、合成キャラクターをモデル通りに保つレビューゲートです。

マルチパス映像

アイデンティティ、環境、カメラ、モーションを制作の異なる段階に分けます。1つのモデルにすべてを任せるのをやめると何が起きるか。

生成世界

AI生成の環境とビジュアル世界を探ります。ロケーション、照明、小道具が計算可能になると何が起きるか。

AI編集

編集判断は人間のままに、映像の発見、構成、仕上げのプロセスをAIがどう加速できるかを探ります。

クリエイティブエージェント

AIエージェントが、クリエイティブプロセスを平らにすることなく、クリエイティブ制作に参加できる方法を探ります。エージェントはクルーの一員になれるか。

ラボから制作へ

公開に至った実験。

ラボは仕事と別物ではありません。サイバーセキュリティシリーズはこれらの探求から生まれました。マルチパスの考え方、キャラクター一貫性のワークフロー、AIアシスト編集を、実際の締め切りを持つ実際の制作に応用したものです。
