フィルムになる必要のあるアイデア、毎月違って見えるブランド、システムが見えないコンテンツ、AIツールはあるのにまだ役立つ成果が出ていないチーム。このページでは、それらの課題、私がそれぞれにどう対応するか、そしてそれを証明する仕事を紹介します。

概要

私が解決する課題。

このサイトの短い版です。私のところに届く課題と、その次に起こることです。

AIへの支出は増えているのに、何も変わっていません。

AIを、日常の使用に耐える、ガバナンスのある、定着した能力に変えます。エージェントが下書きし、人が決めます。

知識は受信箱の中にあり、人が去ると一緒に消えます。

チームが検索でき、信頼できる、ガバナンスのあるナレッジベースを構築します。1つのソース、86ファイル、毎日使われています。

会社は自社を映像で説明できず、AI動画は偽物に見えます。

Occupiedを含む、映画主導の仕事を最初から最後まで演出します。すべてのショットで同じ顔が保たれる、フォトリアルなAIスリラーです。

経営層はパイプラインの実態を把握できていません。

1,717件の案件を、ライフサイクル、スコアカード、ダッシュボードを持つ1つの台帳に統合しました。意思決定はデータに基づいて行われます。

コンテンツが市場のペースについていけません。

ワークフローを再構築し、ソーシャル投稿1件を約4時間半から約40分に短縮しました。

ブランドはチームごとに違って見えます。

すべての成果物で保たれるデザインとブランドのシステムを構築します。テクノロジー企業の中で10年以上、1つのシステムを維持してきました。

ローンチは製品の完成を待てません。

ORIVEX ARC-7のフィルムのように、まだ設計段階にある製品のコンセプトフィルムを演出します。

製品が技術的で、買い手に伝わりません。

6部作のサイバーセキュリティシリーズを含む、難しいテーマを映像でわかりやすく伝えます。1つのビジュアルワールドで統一しています。

自社オーディエンスは誰もが欲しがる資産ですが、築ける人はわずかです。

460本以上の動画と2億5,000万回の再生を持つ子ども向けカタログを作成し、演出しました。

日本への進出には、翻訳以上のものが必要です。

日本で10年間働き、両言語で演出を行います。

課題1 · アイデア

アイデアがあります。完成させる必要があります。しかも、よく完成させる必要があります。

ほとんどのクリエイティブな仕事はアイデアで失敗しません。長い中盤で失敗します。アイデアが薄れたり、遅れたり、それを担えないプロセスに渡されたりします。私は最初の会話から完成品まで仕事を演出します。完成に近いバージョンを早い段階でお見せしますので、見た目は制作前に合意でき、制作後に議論する必要はありません。

コンセプトと脚本

アイデアを具体化します。何を伝え、何を見せ、なぜ響くのかです。

最初から最後までの演出

コンセプト、制作、仕上げまで1人のディレクターが担当します。部門間の引き継ぎがないため、その過程で失われるものはありません。

早い段階での確認

完成に近いバージョンを最初にお見せします。説明ではなく実物を承認いただき、その後の変更は小さく抑えられます。

AIネイティブ制作

人間の演出のもとでAIツールを使って作るフィルムとキャンペーンです。通常の方法で制作した仕事と並べても通用する水準です。このサイトの6本のフィルムが証拠です。各フィルムには、制作方法を正確に示す制作ガイドがあります。映像 / フィルム →

広がるキャンペーン

1つのアイデア、1つのビジュアル言語、多くの展開です。プロモーションキャンペーン、ローンチ資料、セールスキャンペーン、ソーシャルまで、すべて同じキャンペーンだとわかります。

課題2 · ブランド

公開するものすべてが、別の会社から出たように見えます。

静かに起こります。ウェブサイトは1つのことを言い、営業資料は別のことを言い、ソーシャルフィードはさらに別のことを言います。私は1つのテクノロジー企業の中で11年間、そのぶれを止めるシステムを構築し、会社の変化に合わせて進化させてきました。アイデンティティ、ビジュアル言語、ウェブサイト、そして全員が従う基準です。

ブランドアイデンティティ

ウェブ、映像、ソーシャル、営業、イベントを通じて保たれるビジュアルアイデンティティです。

ビジュアルシステム

色、タイポグラフィ、構図、モーションを一度定義し、あらゆる場所に適用します。

ウェブサイト

ウェブサイトの全面リニューアルです。構造、コンテンツ、ビジュアルディレクションを手がけます。

コンテンツ基準

レビューのボトルネックなしに、月に数十点のアセットをブランドに沿わせ続ける編集とビジュアルの基準です。

人を自由にする一貫性

一貫性はシステムが担います。チームはアイデアに集中できます。

課題3 · コンテンツ

アセットを作っています。システムが見える人はいません。

アセットが積み上がります。記事、投稿、資料、動画。それぞれがその瞬間のために作られ、忘れられます。私はコンテンツをエコシステムとして構築します。すべてのピースが、何のためか、誰のためか、何につながるかを知っています。カタログ規模で長年運営してきました。ゼロから構築したチャンネルで460本以上の動画と2億5,000万回を超える再生があり、すべてのピースが次のピースを獲得しなければなりませんでした。

エディトリアル

複雑なテクノロジーをわかりやすく解説する記事です。

ソーシャル

一貫した声と存在理由を持つソーシャルコンテンツです。

ウェブ

組織図のためではなく、実際の読者のために構造化されたウェブサイトコンテンツです。

解説と研修

難しいテーマを画面でわかりやすく伝えます。私が最も多く手がけてきた仕事です。

セールスコンテンツ

意思決定を助けるコンテンツです。バトルカード、アウトリーチ、営業担当者が実際に送るイネーブルメント資料です。

システムの中の映像

コンテンツシステムの横ではなく、その一部としての映像です。映像 / フィルム →

課題4 · AIの問い

チームにはツールがあります。まだ誰も役立てていません。

今、私が最も多くの時間を費やしている課題です。ライセンスが購入され、数人が実験し、何も変わりません。変化を生むのは、実際のワークフローの中に構築され、成果に責任を持つ人がいる、動くシステムです。私が構築するのはそれです。同僚が自分で実行できる制作システムで、品質が保たれるようガバナンスされています。エージェントが下書きし、人が決めます。

人が使う映像システム

同僚のために構築したAIビデオメーカーは、最初の12日間で25本のブランド動画を生みました。専門家でなくても、ハウス基準で自分の動画を作れるようパッケージ化されています。

答えるナレッジ

AIツールが承認済みコンテンツから下書きできるよう整理された企業ナレッジです。人が確認できる出典付きです。

組み込まれたガバナンス

ハウススタイル、検証フラグ、承認ゲートはシステムの一部です。誰も読まないポリシー文書ではありません。

定着する研修

人はシステムを使って実際の仕事を作ることで学びます。私も、実践を通じて教えます。私のDirector’s Chair講座も同じアプローチを教えます。講座 →

課題5 · 締め切り

提案書は数週間を奪い、それでも5人が5通りの書き方をしたように読めます。

提案書は、ビジュアルシステムを備えた論証であり、締め切りの圧力のもとで他の仕事を持つ人々が制作します。私は提案制作も他の仕事と同じように演出します。1つの物語、1つの基準、レビューを経ないものは出荷せず、承認済み企業コンテンツから始める下書きシステムにより、チームは組み立てではなく論証に時間を費やせます。

仕組み

要件 → ナレッジ → 戦略 → 構成 → 下書き → 根拠 → レビュー → コンプライアンス → 承認

成果

複雑なRFPの初稿は、数時間の手作業から約30分に短縮されます。情報の組み立てに費やす時間は減り、論証を強化する時間が増えます。
